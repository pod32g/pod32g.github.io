# Add an account

If Omni Auth is installed on this device, this link opens it on the Add Account screen, ready to
scan a QR code.

If you are reading this page, it isn't installed yet — or your browser opened the page instead of
the app.

- [Omni Auth on the App Store](https://apps.apple.com/mx/app/omni-auth/id6797746360)
- [About Omni Auth](/omni-auth/)

**This link never carries an account.** A two-factor secret in a web link would be sent to this
server every time someone taps it without the app installed, and would sit in browser history
afterwards. Accounts are added by scanning a QR code or pasting an `otpauth://` link inside the
app, where the secret never leaves your device.
