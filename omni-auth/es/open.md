# Abrir Omni Auth

Si tienes Omni Auth instalado en este dispositivo, este enlace lo abre.

Si estás leyendo esta página, todavía no está instalado, o tu navegador abrió la página en lugar
de la app.

- [Omni Auth en el App Store](https://apps.apple.com/mx/app/omni-auth/id6797746360)
- [Sobre Omni Auth](/omni-auth/es/)

Este enlace no contiene nada de tus cuentas. Omni Auth mantiene cada secreto cifrado en tu propio
dispositivo, y un enlace como este solo abre la app: no puede añadir, leer ni cambiar una cuenta.
