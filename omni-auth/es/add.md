# Añadir una cuenta

Si tienes Omni Auth instalado en este dispositivo, este enlace lo abre en la pantalla Añadir
cuenta, listo para escanear un código QR.

Si estás leyendo esta página, todavía no está instalado, o tu navegador abrió la página en lugar
de la app.

- [Omni Auth en el App Store](https://apps.apple.com/mx/app/omni-auth/id6797746360)
- [Sobre Omni Auth](/omni-auth/es/)

**Este enlace nunca lleva una cuenta.** Un secreto de doble factor dentro de un enlace web se
enviaría a este servidor cada vez que alguien lo tocara sin tener la app instalada, y quedaría
después en el historial del navegador. Las cuentas se añaden escaneando un código QR o pegando un
enlace `otpauth://` dentro de la app, donde el secreto nunca sale de tu dispositivo.
