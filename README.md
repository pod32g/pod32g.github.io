# pod32g.github.io

Public project pages and policy documents, served by GitHub Pages at
<https://pod32g.github.io>.

Only published documentation lives here — application source code stays in its own repositories.

## Omni Auth

`omni-auth/` holds the App Store-required policy pages for the Omni Auth iOS app:

| Page | URL |
|---|---|
| Privacy Policy | <https://pod32g.github.io/omni-auth/privacy/> |
| Terms of Use | <https://pod32g.github.io/omni-auth/terms/> |
| Support | <https://pod32g.github.io/omni-auth/support/> |

These URLs are linked from inside the app (`SupportLinks` in the Omni Auth repo) and are
submitted to App Store Connect, so **the paths must not change** once the app ships.

The canonical copies are versioned alongside the app in the private `omni-auth` repo under
`docs/`. If you change one, mirror the change here.
